# 관광산업 통계 통합·상호검증 프로그램 (txc)

문체부·한국문화관광연구원의 **관광산업조사(구 관광사업체조사, KOSIS 등록)**를 기준으로
업체별 매출부터 업종별 통계까지 여러 출처를 모으고, **출처끼리 값을 맞춰 보는** 프로그램입니다.
출처마다 값이 다르면 **비고**에 출처별 값과 기준값 대비 차이율을 적습니다. 조회기간은 **최소 3년 ~ 최대 5년**입니다.

## 다루는 출처

| 출처 | 수준 | 수집 방식 | 주요 항목 |
|---|---|---|---|
| KOSIS 관광산업조사(문체부·문광연) | 업종·시도 | **Open API**(인증키) 또는 내려받은 파일 | 사업체수, 종사자수, 매출액 등 |
| 국세청 사업자등록 상태조회 | 업체 | **Open API**(공공데이터포털 인증키) | 계속/휴업/폐업, 폐업일 |
| NICE비즈라인 | 업체 | 유료 서비스라 **엑셀 내려받기 파일** | 매출액, 영업이익, 종업원수 |
| 관광산업조사 업체별 원자료 | 업체 | 파일(조사기관 보유분) | 매출액, 종사자수 |
| 호텔업 운영현황 조사 | 업체 | 파일 | 객실수, 객실매출, 총매출 |
| 테마파크업(유원시설업) 현황 | 업종 | 파일 | 사업체수, 매출액, 입장객수 |
| 지방행정 인허가(LOCALDATA) 관광숙박업·유원시설업 | 업체 | 전체 CSV 내려받기 | 영업상태, 폐업일, 인허가일 → **연말 영업 사업체수 산출** |
| Open DART(금융감독원, 무료) | 업체 | Open API | 사업자번호 확인, 사업보고서 매출액·영업이익·당기순이익 |

새 출처는 `config.yaml`의 `files:`에 열 대응표만 추가하면 됩니다(코드 수정 불필요).

## 검증 내용

1. **업체 식별 통합**: 사업자번호(10자리·검증식 확인) 우선, 번호가 없는 자료(호텔업 조사 등)는 법인 표기를 걷어낸 업체명으로 연결
2. **업체별 값 비교**: 같은 업체·연도·지표를 출처끼리 비교 → `일치`(허용오차 5% 이내) / `불일치` / `단일출처`
3. **영업상태 점검**: 국세청 휴폐업 ↔ 인허가 영업상태 불일치, **폐업일 이후 연도에 실적이 있는 경우**, 인허가 이후 실적 누락 연도
4. **업종별 값 비교**: KOSIS 관광산업조사 ↔ 호텔업·테마파크업 조사 ↔ 인허가 산출 사업체수
5. **포괄률(참고)**: 업체자료 합계 ÷ 공식 업종통계(표본 차이가 있어 불일치 판정에는 넣지 않음)

단위는 모두 **백만원**으로 바꿔서 비교합니다(원·천원·억원 자동 환산). 업종명이 출처마다 다르면(예: 테마파크업 ↔ 종합유원시설업) `industry_aliases`로 묶습니다.

## 결과 파일 (Excel)

`output/관광산업_상호검증_2020-2024_YYYYMMDD_HHMM.xlsx`

| 시트 | 내용 |
|---|---|
| 요약 | 조회기간, 일치·불일치·단일출처 건수 |
| 불일치목록 | 출처가 여러 개인데 맞지 않는 항목만(비고에 출처별 값) |
| 업체별_통합 | 업체×연도×지표, 출처마다 열 하나, 채택값·판정·비고 |
| 업종별_통합 | 업종×시도×연도×지표 |
| 영업상태 | 국세청·인허가 상태, 폐업일, 비고 |
| 포괄률(참고) / 업체목록 / 원자료(long) / 출처정보 / 수집로그 | |

`--csv`를 붙이면 SPSS·R에서 바로 읽을 수 있는 UTF-8 CSV도 함께 저장합니다.

## 사용 방법 (Windows · VS Code)

```bat
cd tourism_stats
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env          :: 인증키 입력

:: 0) 예시 자료로 동작 확인(인터넷 불필요, 모두 가상 자료)
.venv\Scripts\python -m txc run --config config.sample.yaml

:: 1) KOSIS 통계표ID 찾기 → output\KOSIS_통계표_검색결과.xlsx
.venv\Scripts\python -m txc discover --keyword 관광산업조사 --keyword 호텔업

:: 2) config.yaml 의 kosis.tables 에 통계표ID 입력, data\ 폴더에 내려받은 파일 넣기

:: 3) 실행 (기간 생략 시 작년 기준 최근 5년)
.venv\Scripts\python -m txc run --start 2020 --end 2024 --csv
```

`run.bat`을 더블클릭해도 됩니다(처음 한 번 가상환경을 만듭니다).

### 인증키

- KOSIS: <https://kosis.kr/openapi/> 회원가입 → 활용신청
- 국세청: 공공데이터포털 「국세청_사업자등록정보 진위확인 및 상태조회 서비스」 활용신청 → 일반 인증키(Decoding)
- DART(선택): <https://opendart.fss.or.kr/>

### 파일 준비

- **NICE비즈라인**: 기업 목록·재무 엑셀 내려받기 → `data/nice_bizline.xlsx`. 열 이름과 금액 단위(천원 등)를 `config.yaml`에 맞춥니다.
- **LOCALDATA**: 관광숙박업·유원시설업 전체 자료 CSV → `data/` (cp949 인코딩도 자동 인식)
- 업체별 자료가 `매출액_2022, 매출액_2023`처럼 연도가 열로 펼쳐져 있으면 `format: wide`

## 공식자료만 쓰기

`config.yaml` 맨 위 `official_only: true`(기본값)이면 `official: false`로 표시한 출처(NICE비즈라인 등 민간자료)는 읽지 않습니다.
현재 사용: KOSIS 관광산업조사, 국세청 휴폐업, DART, 지방행정 인허가, 관광산업조사 업체별 원자료.
호텔업 운영현황·테마파크업 현황은 작성기관·정확도 확인 전까지 `enabled: false`로 꺼 두었습니다(확인되면 `true`, `official: true`로 바꾸고 `source_priority`에 추가).

## DART 연결 (무료)

1. <https://opendart.fss.or.kr> → 상단 **인증키 신청/관리** → **인증키 신청**
2. 이메일·사용 목적 입력 → 이메일 인증 → 인증키(40자리) 발급
3. `.env`에 `DART_API_KEY=발급받은키` 입력 (`config.yaml`의 `dart.enabled: true`는 기본값)
4. 실행하면 자동으로
   - 전체 회사 고유번호 목록(corpCode.xml)을 받아 `output/cache/`에 7일간 보관
   - 업체명으로 후보를 찾고, 기업개황의 **사업자번호로 같은 회사인지 확인**
   - 사업자번호가 없는 인허가 업체는 후보가 하나일 때만 연결하고 DART 사업자번호를 채움 → 국세청 휴폐업 조회로 이어짐
   - 연도별 사업보고서 매출액·영업이익·당기순이익(개별재무제표 기준, `fs_div: CFS`면 연결)

- 하루 호출 한도는 인증키당 20,000건입니다. 업체 1곳당 약 1+연도 수(최대 6건)이라 하루 3,000곳 안팎까지 조회할 수 있고, 한도를 넘으면 받은 데까지 저장합니다.
- **재무 수치 API는 사업보고서 제출 법인(상장사·주요 비상장사)만 제공**합니다. 감사보고서만 내는 비상장 호텔·테마파크는 사업자번호만 확인되고 매출은 비어 있습니다.

## 판정 기준 바꾸기

```yaml
validation:
  relative_tolerance: 0.05   # 5% → 0.03 으로 바꾸면 3%
  source_priority: [DART, KOSIS, 관광산업조사(업체별), 호텔업 운영현황, 테마파크업 현황, NICE비즈라인]
```

채택값은 우선순위가 가장 높은 출처의 값이고, 불일치 비고의 차이율도 그 값을 기준으로 계산합니다.

## 알아 둘 점

- 관광산업조사 KOSIS 공표는 **업종·시도 합계**이므로 업체별 매출은 NICE·DART·조사 원자료·호텔업 조사에서 가져옵니다.
- KOSIS 통계표ID는 개편 때 바뀔 수 있어 `discover`로 찾아 넣도록 했습니다. 아직 공표되지 않은 연도는 수집로그에 `자료 없음`으로 남습니다.
- 인허가 산출 사업체수와 관광산업조사 사업체수는 집계 기준(등록 vs 조사 모집단)이 달라 차이가 날 수 있으며, 차이는 그대로 비고에 남깁니다.
- `sample_data/`의 업체·사업자번호·수치는 모두 가상입니다.
